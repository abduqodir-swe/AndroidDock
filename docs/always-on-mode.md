# Always On — переходы 0.3.0

Переключатели независимы: «Автоматически на зарядке» и «Always On — без зарядки».
По умолчанию Always On выключен; существующее согласие на зарядку сохраняется.
Наблюдение активно, если включён хотя бы один режим. Показ возможен на блокировке
при разрешении overlay и условии питания ИЛИ Always On.

| Событие | Результат |
| --- | --- |
| Always On включён, телефон заблокирован без питания | Новый StandBy |
| Always On включён, телефон используется | Ждать следующей блокировки |
| Питание отключено/подключено при Always On | Текущий показ и пауза кнопки питания сохраняются |
| Always On выключен, зарядка включена и питание есть | Продолжить режим зарядки |
| Always On выключен, питания нет | Закрыть/отменить показ, ждать питания при включённом режиме зарядки |
| Оба режима выключены / «Отключить» в уведомлении | Сохранить оба false, закрыть показ, остановить службу |
| Back/Home/кнопка питания | Правила 0.2.1: завершить текущий показ; после использования и блокировки снова доступен |
| Восстановление процесса | Сохранённый Always On не снимает паузу RECOVERY; ждать использования |

Это удержание обычного окна AndroidDock, не системный энергосберегающий AOD.
Блокировка телефона сохраняется, приложение не перекрывает обычное использование.
Новых разрешений, постоянного CPU wake lock или новых виджетов нет.
