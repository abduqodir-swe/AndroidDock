# ADR-001: почему Kotlin + Compose

Дата: 2026-10-09. Статус: принято владельцем.

Для AndroidDock выбран нативный стек Kotlin + Jetpack Compose с DreamService, Coroutines + Flow, DataStore, Room только при необходимости, ViewModel + однонаправленным потоком данных, JUnit + Compose UI tests, Gradle Kotlin DSL и Git + GitHub. Ключевые возможности приложения — системная заставка, AppWidgetHost, NotificationListenerService и медиасессии — тесно связаны с Android, поэтому Flutter, React Native и WebView/Capacitor добавили бы мосты при сохранении значительной нативной части. XML Views не выбран основой интерфейса; необходимую совместимость с Android Views предполагается обеспечить через AndroidView. Kotlin Multiplatform сейчас не используется. minSdk/targetSdk остаются открытыми и будут определены по результатам прототипа в отдельном ADR; ориентир API 26+ для minSdk не является принятым значением.
